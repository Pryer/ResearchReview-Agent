# 退役协议的测试参考

本目录保存移除生产入口前的单动作Main/子Agent协议，供manifest.json列出的既有专项继续检验历史语义。生产代码、配置和脚本不得导入本目录；生产只有TaskMainLoop→DelegationRunner→ActionExecutor→Controller这一条提交路径。

manifest记录原文件SHA-256及显式测试清单。参考代码只调整导入和共享进展/异常工具的依赖，保留旧测试断言；tests/conftest.py仅为清单中的历史协议测试安装参考入口和观察配对。新增v2测试不继承这个fixture分支。此参考组不作为真实Provider质量、性能或A/B/C收益证据。

保留用途：核验历史协议语义、辅助已知旧检查点迁移回归。删除条件：旧数据迁移支持期结束，相关行为断言已全部迁至v2专项，且无需历史协议回归。它不提供运行旧任务的产品入口，不包含第二套生产提交器。
