# 执行提交、恢复与缓存边界

## 动作输入和输出

每轮五字段已包含最新研究摘要，`read_summary` 已从原生工具、JSON 工具目录及
动作注册表移除。无进展上限仍用于实际动作和被门禁拒绝的交付申请，不能通过
重复阅读同一摘要消耗决策额度。

权威状态仍由 Controller 持有，主 Agent 仍只接收五字段视图。专业任务从
`app/agent/action_contracts.py:CONTRACTS` 投影输入，新增字段默认不可见；字段类型来自
`ResearchAgentState`，不再为未声明类型的字段自动退回 `Any`。以下是主要读写依赖，
完整字段白名单以 `CONTRACTS` 为准。

| 动作 | 主要输入 | 可提交产物 |
| --- | --- | --- |
| `search_and_rank` | 目标、查询、筛选、既有候选和路线摘要 | 候选、排序、筛选和检索诊断 |
| `fetch_metadata` | 候选、排序、元数据和已有文档 | 元数据、受控 PDF 引用、解析资料、筛选结果 |
| `extract_paper_cards` | 元数据和解析资料 | 证据卡 |
| `validate_routes` | 证据卡、候选路线、分析约束 | 路线、归属、覆盖诊断和分类 |
| `cluster_papers` | 证据、路线、分类和恢复约束 | 聚类、分类、主题综合 |
| `plan_claims` | 证据、主题、路线和声明约束 | claim 计划、对齐结果和证据门禁 |
| `generate_deliverables` / `rewrite_sections` | 授权卡片、claim、写作计划、分配、现有章节、核验约束 | 正文、检查点、引用、逐句核验和质量状态 |
| `validate_result` | 正文、证据、声明和最终约束 | 核验结果、引用和交付门禁 |
| `targeted_search` | 检索、分析、写作和恢复输入的显式组合 | 有界补检索及其证据、授权、引用修复产物 |

每个动作还读目标与必要轨迹，写执行诊断。`targeted_search` 的既有实现确实包含
多个阶段，因此保留显式复合契约；它不是任意字段通行证。写作任务不读取原始
`parsed_papers` / `pdf_paths`。共享预算、主控上下文和任务历史由控制层管理，
专业任务不能直接提交这些字段。用户主题、显式年份、参考文献数等保护字段不可修改。

写作、改写和独立验证均可提交 `claim_alignment` 与 `claim_citation_consistency`，
因为写作动作内部也执行完整的写后校验。背景动态提纲只在本次写作计划编译中传递，
目标与比较维度进入 `WritingPlan`；临时提纲不写入全局状态，不复用旧状态中的提纲。
后台执行失败通过统一公开原因映射显示，内部字段和原始异常仅留在服务端日志。

任务结果在生成端和提交端各校验一次：动作/角色/任务身份、输入指纹、状态版本、
输出键、字段删除、字段类型；同一字段同时设置和删除也会被拒绝。引用资料还要
通过会话归属、动作允许的资料类型、角色权限和版本检查。

## 数据库事务与预算

持久化路径是 `ResearchConversationService.handle/revise`。执行期数据库对象通过
ContextVar 传播，不进入模型上下文。直接调用 graph 的测试/脚本仍是内存执行模式。

- `research_runtime`：会话租约、CAS 版本、取消位、最新状态和累计预算。
- `research_tasks`：动作幂等键、来源版本、运行/完成/失败/阻断/过期/取消/中断状态。
- `research_attempts`：每一次外部模型请求的预留和已知用量，包括重试与备用请求。
- `research_checkpoints`：不可变的已提交研究快照。
- `research_events` / `research_memory_cursors`：追加事件及增量摘要游标。

任务发起先落库，外部调用不占写事务。成功提交通过
`session + version + owner + unexpired lease + not cancelled` 条件更新；状态、
资料、任务完成记录、事件和预算一起提交或一起回滚。后台 job 的领取也使用
`queued → running` CAS，进程内 guard 不再是唯一的重复执行防线。

真实请求发出前预留预算，收到响应先记录用量，再做 JSON、工具参数、取消及期限
检查。因此解析失败、空内容重试、备用切换、取消后收到的响应都不能漏计。
失败任务保留已消耗预算；恢复不清零。若进程在请求发出后崩溃，无法确定服务商
是否已计费，该请求标为 `uncertain`，按原预留保守计入估算消耗，不伪装成真实
usage，也不自动重放原任务。过期所有者的迟到响应不能覆盖新执行的账本。

进程内展示指标与数据库预算账本职责不同。展示指标统计服务商实际返回的 usage，
预算账本还包含缺少响应时的保守估算，二者可以不同。缓存命中率分母使用已上报的
hit + miss；没有缓存数据时命中率为 `None`。这里不把 token 数伪装成供应商账单金额。

账本限制输入与输出总 token（含缓存命中），不是折算金额。当前没有已验证的
服务商 tokenizer，预留使用请求 UTF-8 字节数加协议余量及完整 `max_tokens`，
不使用字节除三、平均输出比例或缓存 EMA 折扣。该估计有意偏保守；实际 usage
先结算再检查超支/取消/期限，越界响应不会继续解析和用于提交。缺少 usage 或
崩溃未决的调用按完整预留估算。服务商若返回异常大用量，已发生费用无法撤回。

新会话默认上限为 `1000000`，已有账本保留原额度。管理员可对空闲会话显式更新：

```bash
python scripts/update_session_budget.py --session-id YOUR_SESSION_ID --expected-limit 100000 --token-limit 1000000
```

该操作通过数据库 CAS 校验原额度、版本、账本及执行占用，拒绝活动任务和未决请求，
不清零用量、不接管租约、不启动研究；变更记录在事件表。随后仍需显式检查点恢复。
读取会话时独立刷新账本，即使研究检查点版本不变也能取得最新额度。

公开停止原因区分 token 预留不足、实际超支、次数额度、执行超时和无进展。
字符串错误可安全处理，内部异常文本保留在诊断记录，不原样拼入用户回复。

公开会话保存也验证租约和版本。取消与提交由数据库写入顺序裁决：取消先提交则
研究结果无法随后提交，但已发生的消耗仍结算。旧后台 worker 的取消异常处理
不能覆盖新执行。已发出的外部请求仍依赖客户端超时/协作取消，不宣称远端立即停算。

## 历史与恢复

会话历史在展示窗口保留最近 50 条之前逐条归档。条目标记避免重复保存，但相同
文本的不同新消息仍保留各自发生次数；归档内部键不会经会话历史 API 输出。
旧会话用数据库事件标记执行一次迁移，过去已截断的历史不能凭空恢复。

摘要从已提交游标之后读取新事件，摘要资料和游标在调用方同一事务保存；问题解决、
决定失效不会因再次摘要而复活。原始事件始终保留，摘要只是可重建视图。

会话读取会优先恢复比公开会话更新的已提交研究检查点，并从账本恢复最新消耗。
Pydantic 诊断保存为结构化字段；大型任务补丁按 JSON 片段保存并原样恢复，
不靠字符串化对象或截断证据避开资料大小约束。

对 `running/failed/cancelled/blocked` 的中断会话，可通过原 Agent 请求 API 显式发送：

```json
{
  "session_id": "原会话 ID",
  "user_query": "继续上次研究",
  "resume_from_checkpoint": true
}
```

恢复保留原研究目标、证据、年份和篇数要求，开始一个新的操作序号，交由主 Agent
重新决定未完成工作。待澄清会话仍走澄清回答，已完成会话仍走修订入口。崩溃进程的
租约到期前不能被另一个执行抢占；重启不会假定所有其他进程都已死亡。没有已提交
检查点、资料损坏或缺失会明确报错。恢复不绕过质量门禁，也不会自动提高预算。

启动时 `init_db()` 会添加上述新表；也可运行
`python scripts/migrate_agent_runtime.py`。迁移幂等，不删除旧表、历史或研究资料。
更新后需重启服务；本次开发未替用户重启正在运行的服务。

## 提示词与章节复用

证据卡、章节改写和完整交付物写作提示词均采用固定规则/输出结构在前、动态研究
材料在后。原生工具请求只通过 `tools` 发送工具目录，JSON 回退仍携带文本工具目录。
规则、输出约束和引用核验保留，不以删证据提高命中率。

章节指纹与渲染共用授权投影和 claim 约束匹配。复用判定前生成确定性证据草稿，
覆盖实际原文、授权后的本节卡片、主题/范围/重点、引用政策、路线、分配、筛选、
末路线综合义务，以及真正注入每一节的授权综述清单。无关论文和单纯全局快照变更
不会无故使全部章节失效。旧指纹因 schema 变化自动失效。

这些改动改善应用复用和服务商前缀缓存条件；没有在客户端实现模型 KV cache。
真实命中率以返回的缓存字段为准，单次验收不是相同质量下的节费对照实验。
