## P0-D：运行前证据可行性检查

本轮先采用人工表和现有检索能力，不增加生产硬门禁。两级预查通过只代表值得启动实验，
不能授予主张权限，也不能代替最终引用、范围和完整性验证。

### Gate A：低成本元数据预查

1. 冻结主题、年份、交付物和最低唯一引用要求 N，记录来源及检索时间。
2. 检查年份、主题相关性、摘要可用性和可核对的唯一论文身份，排除重复版本。
3. 本轮正向对照以去重候选数至少 **2N** 为初筛条件；DOI、arXiv ID 或可核对的来源记录均可用于身份核对。
   DOI 不是必需条件，候选数量不代表证据合格数量。此比例不得推广成所有生产任务的硬门禁。
4. 未达初筛条件记为本轮对照尚不可行，不据此推断一般任务一定无法交付；已有 N 篇合格证据的生产任务仍按原门禁判断。

### Gate B：证据预审

本轮正向对照限定为最低 3 篇唯一引用的小规模任务，人工预审至少 **3 篇不同论文**。
每篇记录：身份及版本、年份、主题关系、可合法访问的证据、证据位置、拟支持的主张及限制。
判断证据是否足以支撑拟议表述；仅有标题、摘要关键词命中或身份可查不算通过。
摘要可以支持的表述强度必须受其内容限制，无法核对的方法、数字或结论不得写入。
