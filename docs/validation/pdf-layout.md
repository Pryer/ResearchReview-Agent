# PDF 版面对照评测

`PDF_LAYOUT_ENABLED=true` 为新解析启用版面检测。双栏候选按页坐标分区，只有两栏存在垂直重叠且清洗后的非空行多重集一致时才采用重排。检测到表格的页面沿用原文本顺序，另记录候选网格、单元格坐标和可唯一定位到页面文本的字符区间。同页重复的数值可通过单元格矩形定位。证据抽取继续读取页面文本与页内区间。

## 固定对照

运行 `python -m pytest tests/test_document_ingestion.py -q`。测试现制 PDF，按预设版面与原文对照。

| 场景 | 检查 |
| --- | --- |
| 双栏 | PDF 内容流先写右栏，候选解析恢复左栏再右栏 |
| 跨页续段 | 下一页沿用上一页的章节身份，两页的摘录分别按原页偏移回读 |
| 实验表格 | 网格值同时绑定方法行和指标列。交换两行中的重复百分比可测出错列。重复值省略字符区间。 |
| 入库契约 | 版面解析使用独立处理配置标识。页面文本变化时来源指纹随之变化，分块通过来源完整性验证。 |

## 真实原文抽查

对此前已缓存的 *Benchmarking Large Language Models in Retrieval-Augmented Generation* 第 3 至 5 页渲染并核对。样本分别覆盖流程图与双栏、跨页续段、真实实验表格。

| 检查项 | 实测 |
| --- | --- |
| 第 4 页双栏 | 5 个阅读位置锚点在默认与候选解析中均按视觉顺序排列。本页候选顺序与默认一致。 |
| 第 3 至 4 页续段 | 两页的段末和段首片段均可从所在页读回。 |
| 第 5 页表 1 | 原文中抽查 ChatGPT 与 ChatGLM2-6B 的 4 个方法与数值对应项，候选网格完整恢复 0 项。该表的合并表头与部分列边界需要进一步处理。 |
| 第 3 至 5 页证据区间 | 4 个章节区间均能从候选解析的对应页面回读。第 3 页流程图也触发了网格候选。 |

当前保留原解析为默认值，版面检测用于对照。表格诊断保留几何候选，阅读顺序标为未验证。跨页保留章节身份和页内锚点，OCR 与复杂表格还原待评测。恢复旧任务时沿用已提交的解析结果。测试版面对比时可从同一原始 PDF 分别发起新解析。
