# Main质量恢复闭环：实现与验证

记录时间：2026-11-10 00:25:40 +08:00。详细协议见main-quality-feedback-loop.md。

## 实现

Main依据结构化质量反馈选择改写、补检索或再分析。Search只提交候选，新材料经Analysis提取与授权后才参与Writing。新候选独立验证后才继续研究；残稿返回unusable/blocked。恢复建议、共享预算与历史复用generation_recovery，查询绑定诊断版本，过期查询不可复用。

仅当本次独立核验确认安全回滚时才允许Main换方案；历史回滚和过期验证仍受循环保护。业务操作已原子提交后，子Agent汇报协议失败显式交回needs_help、保留真实结果，不重复工具；业务尚未执行的协议失败仍传播。原模型纠错次数、目标/年份/最少唯一引用、每篇8块预算及发布门禁保留。

常规显式引用任务目标约2倍合格候选，首批证据池约1.5倍；小任务至少5篇绝对余量，大额绝对余量上限40保留。

## 最终离线回归

新增20项行为测试，包含原生/JSON完整跨角色恢复、短稿、版本、权限、预算、可信回滚、已提交操作的汇报失败，以及门禁通过后的收尾反馈。

## 边界

原文位置回读不代表人工语义验收；本轮尚未成功交付完整正文。Main停止理由属于运行记录，不等同于独立人工对每条事实的结论。当前恢复循环已经发生，后续质量改进仍需围绕合格的直接证据和实际主张支持。
