日期：2026-11-17，Asia/Singapore。对应S2—S4的兼容恢复和局部资料操作。

## 已知v1活动检查点的迁移

在显式选择v2的恢复入口中，TaskMain检查历史active_subagent，将已知格式转换为内部legacy_single_v1。新授权固定原角色、唯一operation、原参数和单Action上限，不进入模型能力目录。

| 历史状态 | 处理 |
| --- | --- |
| 尚未提交 | 校验原目标/约束、输入指纹与参数；恢复同一动作，保留累计费用、全局预算和已用局部轮次 |
| 已提交但尚未汇报 | 核对数据库Task completed记录、角色/操作、完整结果及输入/输出指纹；导入已提交Invocation，直接汇总，不重复调用工具 |
| 历史analysis.validate_result | 转入当前Check身份，重新核验当前候选；旧通过报告不自动升级为当前核验结果 |
| 目标改变、未知格式、缺少提交证明 | 拒绝迁移，保留原检查点，不猜测补齐或重放 |
| 已完成记录与同一mandatory队列项冲突 | 明确拒绝歧义，既不擅自出队，也不重新执行 |

迁移元数据、Grant、导入Invocation、活动指针、轨迹配对和检查点在同一CAS快照事务中写入。迁移器不另开嵌套提交；故障会回滚全部迁移写入。提交时强制从数据库刷新业务版本，若其他会话已推进版本则拒绝迁移，不以Session缓存覆盖新版本。旧轨迹、原参数、轮次和结果保留为审计。

业务版本初始化映射到已有提交状态；迁移本身不增加远程调用或模型费用。旧局部轮次达到上限时，恢复会交权，不重置执行额度。

恢复优先读取执行数据库中的活动工作与有效配置，避免较旧的会话editable副本覆盖显式架构配置修订。未显式选v2的旧任务仍按冻结配置运行；本批没有修改默认入口。

## paper_ids子集重建

`evidence_build`允许scope.paper_ids指定最多32个当前已核验详情中的唯一论文ID。服务器将该委派收窄为一次direct extract_paper_cards，不让子集动作改写全局路线、主张或正文。

输入投影、Artifact引用、文件/向量资源、抽取缓存均只包含获准论文。输出回填通过同一结果合并器按paper_id更新选中卡片；范围外卡片、缓存和待重建标记保留。不同论文不能通过相同缓存键互相覆盖，越界输出或Artifact写入直接拒绝。

局部抽卡结束后交回Main，继续由全局证据、主张和交付门禁判断后续工作。范围内证据发生变化时，原全局派生授权仍按既有规则失效。最低引用数、年份与其他用户约束不因子集操作改变。

子集委派不能替代或消费全局mandatory动作；当前只支持证据卡局部重建，不开放对子集生成综述或局部覆盖整套路由/主张计划。
