# 自动运行报告：实现与验证

日期：2026-11-11；环境：Windows、conda `rragent`。

## 已实现

- 默认自动输出易读HTML时间线、Main逐轮上下文和差异、专业Agent的契约输入/角色记忆/工具步骤/返回结果，以及结果与检查说明。大文本使用标明长度与内容哈希的预览，原始资料通过源检查点和资料引用定位。
- 在Main动作选择后直接捕获五字段视图，包含没有新增模型请求的策略交接轮；专业委派在执行前与完成后分别记录，同角色记忆与当前输入分开。
- 会话服务、直接Python图入口和后台任务复用同一报告服务；嵌套调用不重复导出。入队失败、取消、澄清、阻断、执行失败及重启中断均有对应报告或明确的缺失说明。
- 报告注册为service-only诊断资料，沿用API密钥保护；会话/报告ID同时匹配，下载文件采用名单。HTML限制外部网络及表单，前端下载时不将密钥放进URL。
- E2E自动在本轮目录复制HTML与ZIP；不要求同时启动API。报告观察、读取或导出失败独立记录，不覆盖真实结果或取消异常。

## 页面和数据范围

历史任务仍保留19次模型输入与5次策略交接的区别；没有保存的历史快照不伪造补齐。新执行从观察钩子额外记录策略交接上下文。报告不输出内部思考协议，业务模型每次HTTP完整Prompt未在本功能中逐次归档。

浏览器实屏自动检查因Computer Use原生连接不可用而未完成，错误为`native pipe is unavailable`；已完成页面语法和交互逻辑检查，未宣称像素级或实机手机验收。

## 收敛检查

保留既有Main规划、专业Agent执行、Controller权限/租约/CAS/取消和预算边界。没有新研究调度器，没有为报告发起模型请求。报告读取冻结到本执行已知版本，预算读取还匹配执行所有权；不会读取同会话后续执行。原用户修改、旧报告和失败日志保留；原技术版HTML归档，原书签切换为易读版。没有提交或推送。
