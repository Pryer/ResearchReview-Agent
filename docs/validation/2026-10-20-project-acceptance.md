## 真实任务的复现边界

任务集：`examples/real_e2e_tasks.jsonl`，包含目标论文检索、构造空证据对照和小规模
研究背景写作。`scripts/run_real_e2e.py` 经真实 `ResearchConversationService.handle`
运行，每次创建独立 SQLite 库，不自动回答澄清，不降低年份、引用数或门禁。

实际配置为当前主备 `deepseek-v4-flash`，实验排序使用 rules；每次记录来源、预算、
超时、代码 SHA、改动摘要哈希、脚本/任务集哈希、Provider 返回 Token、估算、
账本、终态、操作与检查点。Token 统计不是供应商账单金额。运行结果及本地原始库
保存在 `data/real_e2e/20261020/`，不提交 Git。

首轮 OpenAlex 返回长时间 Retry-After，后续实验停止使用该来源；Semantic Scholar
也观察到限流。后续采用 arXiv + Crossref，来源差异已进入每次配置记录，不将来源
变化或重跑前后的随机波动归因为算法提升。

复现示例（需要已有可用的模型配置，调用会产生实际用量）：

```powershell
python scripts/run_real_e2e.py --task T01 --sources arxiv,crossref --token-budget 360000 --output-dir data/real_e2e/reproduction
python scripts/run_real_e2e.py --task T05 --sources arxiv,crossref --output-dir data/real_e2e/reproduction
python scripts/run_real_e2e.py --task T06 --sources arxiv,crossref --token-budget 360000 --output-dir data/real_e2e/reproduction
```

一次脚本正常结束表示记录已生成；是否满足研究目标必须查看任务终态和独立审查，
不能按脚本退出或 HTTP 成功判定。人工审查字段保持 pending，不把 Agent 的辅助
核查写成独立人工结论。
