# 十二条源码走查建议的处理结果

本次继续修复来源分组、重启状态一致性和重复 BM25 建索引，并复核前序修复。
以下区分实际修复与仍保留的设计取舍。

| 条目 | 处理结果 |
| --- | --- |
| 1. 停止异常中的观察写库 | 已有修复确认：终止观察只更新内存，不归档 Artifact 或失败记忆；清理失败不覆盖原停止原因。 |
| 2. 新研究继承旧工作预算 | 已有修复确认：Owner 领取新研究时结算旧未决费用，重置工作计数与期限；保留累计 Token/请求，恢复、澄清与修订不清零。 |
| 3. 单块 JSON 错误熔断整篇 | 已有修复确认：仅该块响应格式失败，后续已选块继续；Provider/控制异常仍停止，默认八块预算不变。 |
| 4. 请求失败污染目标与轨迹 | 已有修复确认：暂存新目标及压缩轨迹，通过窗口检查后才提交。 |
| 5. 同团队摘要误计独立来源 | 本轮修复：DOI 去重与作者/数据依赖取传递合并；同末位作者缺数据时保守合组，未知作者不增加独立组。既有主张门禁据此降级。 |
| 6. 相同条件的死分支 | 已有修复确认：删除不可达分支，保留支持/越权表达的原检查。 |
| 7. 重启后会话停在 running | 本轮修复：Job 与仍归属它的运行中会话在同一事务更新；不覆盖较新 Job 或终态会话，不改证据快照。 |
| 8. Controller 执行前隔离 | 未复现所述 Handler 共享业务状态：BaseSubAgent 在调用 Handler 前通过 build_task_state 创建契约工作副本；已有执行后取消的嵌套状态回归。保留该边界，不再额外复制整个状态。 |
| 9. 筛选缓存未外置 | 已有修复确认：缓存按 json_object 分片持久化并恢复，兼容旧内嵌状态，命中刷新最近使用顺序。 |
| 10. 重复分词与建 BM25 | 本轮修复：论文级多 Query、单篇七类字段 Query 分别共用一个调用内索引，保留评分及稳定排序。 |
| 11. 状态历史与投影开销 | 已修通信/轨迹优先压缩、轻量子角色控制视图、执行期就绪缓存与同义字段去重。生产仍保留追加式状态消息以维持请求前缀；瞬态状态栏仅有离线对照，未启用。 |
| 12. 中文预留偏保守 | 移除 JSON 容器空白，新增预留与实际输入诊断。未采用语言比例估计或平均输出折扣：当前没有已验证的服务商 tokenizer，这些比例不能保证硬预算边界；完整 max_tokens 仍预留。 |

来源分组是保守的工程代理，不能证明作者团队或实验实际独立；未补造缺失元数据。
唯一参考文献计数不受来源强度分组影响。新来源评级政策加入 Check/草稿指纹，旧
通过报告失效；Check 只读复核并阻断过强授权，由 Analysis 重新授权，不改历史已
交付正文。证据不足、引用核验及发布门禁继续执行。

本轮新增 [12 项根因回归](../../tests/test_deep_review_regressions.py)，覆盖来源依赖、
旧计划降级与只读阻断、政策变更失效、BM25 等价评分/语料复用、重启事务一致性及
Token 预留结算。现有消融用例改为注入索引对象，并断言两条查询只构建一个索引。
相关定向 158 项通过；最终全量 **2124 passed、17 skipped、11 warnings，107.01 秒**。
