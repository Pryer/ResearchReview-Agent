# 轨迹诊断修复验证

日期：2026-11-11，Asia/Singapore。环境：Windows、conda rragent。

## 实现范围

- 完整逐句核验补齐恢复目标，保留具体句子与证据；过期报告不产生执行目标。
- 交付物类型按当前计划展开为章节ID；无效目标返回可恢复拒绝，不创建写作任务。
- Writer通过既有Prompt模块读取完整恢复问题；正文仍按既有渲染器生成，随后独立Check。
- 恢复历史记录基础版本和逐目标结果；跨版本不把句序编号当作稳定身份。
- 发布指纹同时用于准入和底层幂等，包含书目及公开核验变化，排除随机报告ID。
- 同证据/授权和同质量向量的无进展重写不能靠改措辞重置；不提高预算或放宽约束。
- 保留推断要求自身来源，阻止主题实体把它升级为用户要求；已回答澄清不再从计划副本恢复。
- 质量失败记忆增加分类并去除委派汇报重复；保留旧agent_failure事件的兼容读取。
