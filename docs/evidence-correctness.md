# 证据正确性：来源、身份、支持资格与上下文

本轮针对本地审查的 A/B/C/D 修复，不更改 Chunk 参数、检索默认模式或数据库后端。

| 问题 | 当前行为 | 主要入口 |
| --- | --- | --- |
| A 历史卡片自证 | 不再从 method/results 等字段伪造原文；无独立来源时报告 source_unverified | evidence_support.py、verify_claims.py |
| B DOI 冲突 | 强标识冲突时拒绝弱标题及歧义标识桥接合并，保留可能重复记录 | deduplicate.py |
| C 相似度误授权 | 相似度只召回；当前确定性字段授权要求逐字支持及有效来源绑定 | extract_paper_card.py、evidence_support.py |
| D 核验文本截断 | 展示 text 与 verification_context 分开；模型读取完整已选证据，超限不截断后继续核验 | verify_claims.py |

## 来源边界

EvidenceSpan 必须有 evidence_id、非空原文、abstract/full_text/table 内容来源，以及有效
offset 或页码/来源链接。成对 offset 必须非负、有序且长度与原文一致；存在片段哈希时校验它。
新抽取对摘要、页面、全文或章节原文回读，逐字核对位置，保存 source_status、
source_text_hash 与 source_document_hash。来源回读失败的片段不获得字段支持资格。
摘要身份与全文权限仍遵守原有 access_level；元数据片段只解释书目信息。

旧卡片缺少 EvidenceSpan 时可以保留历史展示数据，但不能用于证明自身字段正确。
旧的非空 spans 也不能单凭“存在”通过；必须符合上述来源契约。
为保持历史数据可读，已有来源定位但未记录哈希的 spans 仍兼容；这不能证明已对全部历史
PDF 重下载、回读或人工核对。哈希用于变更检测，不是真实性签名。需要更强保证时，从
合法可访问的原始材料重新抽卡。此次不改写历史数据库和真实验收结果。

## 字段与主张的不同资格

正文式字段采用规范化空白/大小写后的完整原文一致性；dataset/metrics 短标签只允许
有边界的原文片段匹配，不能遗漏检测到的否定或条件词。这些规则是保守的确定性准入，
不是通用语义蕴含算法。改写、翻译的字段不再靠重合分数取得 explicitly_reported。

历史布尔值在字段质量门禁、路线主张、背景规划、主题综合及 Writer 投影处重新判断。
缺证据的写前主张被删除并记录失败，不因删除后列表变空而自动获得“通过”。最终写作
主张仍须执行语义验证、引用检查和发布门禁；原文逐字存在不证明作者结论本身真实，
也不证明跨论文推论成立。本轮没有新增字段改写的独立语义授权存储机制。

## 身份合并边界

不同 DOI 或冲突 arXiv 标识禁止单凭标题自动合并；相同 DOI 保持优先身份规则，
跨来源确证的相同标识及无冲突桥接继续去重。标题冲突候选保留可能重复关系供诊断。
更正关系不等于相同引用身份。本轮没有新增预印本/正式版的关系解析器，未确认时保留
两条记录。已经被旧算法合并丢失的记录，需要从原始检索结果重新处理，不能凭空还原。

## 核验上下文与恢复

报告保留用于 UI 的 text（最多 360 字符），独立保存 verification_context 与 source_span。
CLAIM_VERIFICATION_MAX_CONTEXT_CHARS 默认 12000，范围 1000—64000，按单条主张
去重后的完整已选证据字符数计算，不是 Token 数。选证据仍有检索边界，不代表整篇覆盖。
超过上限时明确报告 insufficient_context，跳过该主张的模型调用，阻断其发布资格；
应补充完整且有界的证据、修正主张或删除主张。不要把它当成模型重试能补齐的语义待验。
现有模型调用预算、取消与租约边界继续执行。

验证器升级为 atomic-entailment-v4，指纹包含证据规则、原文/位置、访问级别与上下文
上限；旧局部报告、语义缓存和已验证草稿不能直接复用。旧版本报告即使标为通过，也
需要重新核验；source_unverified/insufficient_context 不能被总体支持率或 best-effort 放行。

## 回归验证

tests/test_evidence_correctness.py 覆盖最小反例和正常路径，包括独立摘要、强标识冲突与
真重复桥接、肯定/否定翻转、无效 offset、哈希变更、序列化旧卡片、主张规划/主题/写作
授权、360 字符之后的限定、超过上下文预算、预算变化与缓存失效、旧草稿隔离及发布门禁。
现有正向测试补齐独立原文 fixture，保留各自计数、恢复和写作目标断言。

模型全部使用受控替身；这些回归证明逻辑边界，不证明真实模型正确率、幻觉率改善、
PC01 成功或 PostgreSQL 原生并发。原始审查与本轮结果见
[本地全链路审查](validation/2026-10-27-rag-chain-review.md)。
