# 对话式前端使用指南

更新：2026-09-22。当前主前端为 `app/frontend/chat_app.py`，支持多会话界面、
研究范围澄清、后台任务轮询、取消和明确标注的可用草稿。旧的
`app/frontend/streamlit_app.py` 已不存在，不应再作为备用启动入口。

## 启动与配置

在项目根目录、已安装依赖并配置环境的终端中启动后端：

```bash
python run_api.py
```

另开终端启动前端：

```bash
python run_chat_frontend.py
```

也可直接运行 `streamlit run app/frontend/chat_app.py`。API 地址来自部署配置
`FRONTEND_API_BASE_URL`，侧边栏只展示，不能在浏览器中修改。配置
`APP_API_KEY` 时，前端自动携带 `X-API-Key`。

前端通过后台任务接口提交研究，每 2 秒轮询一次；单次 HTTP 请求超时为 15 秒，
不等于整个研究的时限。当前聊天请求未使用 `FRONTEND_REQUEST_TIMEOUT` 控制该值。
研究执行时限及累计用量限制分别由服务端配置与持久化预算控制。

## 使用流程

1. 新建对话，输入主题、年份、目标引用篇数和所需章节。
2. 如出现范围澄清，在同一对话回答；原始年份与引用要求会保留。
3. 查看后台状态及当前步骤；执行中可以请求取消。
4. 按结果状态查看正文、论文、来源诊断、引用核验和质量缺口。

例如：“生成近三年的课堂行为识别研究背景和研究现状，引用不少于40篇”。
这是任务输入示例，不代表已经完成真实 40 篇交付验收。

`needs_clarification` 表示等待回答；`partial` 表示带限制的降级结果；
`blocked` 表示当前要求未满足。可用草稿按钮只在后端允许的条件下显示。
“基于现有证据生成草稿”不会自动降低原始引用篇数或放宽显式年份。

当前界面一次跟踪一个活动任务，研究执行期间聊天输入禁用。切换会话不会取消
后台任务。点击取消后可能先显示 `cancel_requested`：已发出的远程请求仍受
客户端超时与协作取消约束，已发生用量继续记录。

## 界面历史与数据库状态

| 数据 | 保存位置与边界 |
| --- | --- |
| 侧边栏对话列表、当前聊天气泡、活动任务句柄 | Streamlit `session_state`；刷新或重建浏览器会话可能丢失，当前界面不会自动从数据库重建 |
| 研究会话、证据、已提交检查点、累计预算 | 服务端数据库；不随界面刷新删除 |
| 历史事件与摘要 | 服务端增量归档；公开会话历史只返回保留窗口，不是全部事件 |

侧边栏删除按钮只删除本次界面中的对话，不删除数据库研究记录，也不取消任务。
需要恢复查询时使用原来的 `job_id` 或 `session_id`；新建空对话不会自动找回它们。
当前没有“恢复中断检查点”按钮，也没有从数据库列举并重建全部历史对话的 UI。

## 中断、修订与排查

- 查询已有任务：`GET /api/reviews/jobs/{job_id}`。
- 查询已有会话：`GET /api/reviews/sessions/{session_id}`。
- 中断后显式恢复：向 `POST /api/reviews/jobs` 发送原会话 ID 和
  `resume_from_checkpoint: true`；需已有检查点且无其他活动任务或有效租约。
- 已完成结果的论文排除与增量重生成：`POST /api/reviews/jobs/revise`。

上述恢复和修订接口的参数与限制见 [多轮会话指南](multi_turn_research.md)。
服务重启不自动重放运行中的研究；恢复保留累计预算，预算耗尽可能继续阻断。
如果进度不更新，应查询任务状态和来源诊断；不要仅凭界面等待时间认定成功或失败。

架构和本地验证边界见 [执行与恢复说明](agent-runtime-and-cache.md)及
[2026-09-22 验收记录](validation/2026-09-22-runtime-cache.md)。
