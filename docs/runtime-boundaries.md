# 下载、核验复用与报告边界

## PDF 下载

开放获取资格和网络出口分别验证：来源政策继续生效，arXiv 仓储按解析后的主机名精确识别。下载仅支持 HTTP/HTTPS，拒绝 URL 凭证、非公网 DNS 结果（包含混合公网/私网答案）、映射 IPv6、保留与组播地址。重定向最多五次，每跳复核，校验后的 IP 直接绑定连接；原始主机用于 Host、TLS SNI 和证书验证。

PDF 专用客户端不继承环境代理与 netrc；需要代理出网的部署应提供另行验证的出口方案。当前使用首个合法 DNS 地址，未实现多地址连接竞速。

下载、流读取、重试和批量等待共用执行上下文。read1 在有数据时及时返回，取消后关闭响应、清理部分文件；控制异常透传，普通单篇失败仍可隔离。每次连接/读取等待最多三秒并受剩余任务期限约束，批量仅维持 workers 数量的在途任务。

这是协作式取消：系统 DNS 解析、响应头解析、PDF 解析及底层不可中断调用不具备进程级硬抢占保证；三秒是 socket 等待上限，不是所有情况下的端到端取消 SLA。需要硬期限时应使用独立 Worker 进程及部署层出网限制。

## 核验身份

Check 输入指纹、主张蕴含缓存、局部复验的历史报告共同绑定 verifier profile。身份覆盖主备 Provider、模型、端点哈希输入、推理配置、核验提示、角色前缀、工具目录、阈值和上下文限制。凭证不参与身份，也不输出端点原文。缺少新身份的历史结果重新核验。

主备模型是当前配置允许的执行来源；任一配置变化使身份变化。实际成功响应保存 Provider、请求模型、响应模型和回执标识，缓存命中与局部复验保留原来源。自定义 LLM 未提供回执时标记 unreported。Provider 在不改变名称的情况下热更新权重，需要主动更新模型版本标识或核验提示版本，客户端无法推断远端权重变化。

## 报告脱敏

捕获和导出复用 safe：过滤结构化敏感字段及内部思考字段，对自由文本、字符串键和路径中的认证头、密钥赋值、敏感 URL 参数、URL 内嵌凭证和明确的密钥格式进行遮盖。处理仅作用于报告副本，不改研究状态或原始证据。

这是一组明确凭证模式的脱敏规则，不承担所有个人信息或任意格式秘密的识别。分享报告仍应按研究资料的访问范围管理。DOI、百分比和普通论文文本纳入误删回归。
